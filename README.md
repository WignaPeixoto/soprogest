# soprogest
Sistema de gestão para proteção animal — ONG Sopro da Vida
## Revisão técnica e qualidade

O SoproGest utiliza Python, Flask e SQLite, com separação entre a lógica da aplicação, os templates HTML e os arquivos estáticos.

A organização do projeto facilita a manutenção e a evolução das funcionalidades.

A qualidade do MVP é acompanhada por testes automatizados com pytest e integração contínua pelo GitHub Actions.

Como melhorias futuras, estão previstas a modularização das rotas, a ampliação dos testes e o fortalecimento das validações de segurança.
